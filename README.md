# Cruise Control System – Time-Domain Simulation (MATLAB)

This project models and analyzes a basic cruise control system using MATLAB. Based on Franklin's *Control Systems Engineering*, Chapter 2, it walks through the dynamic behavior of a first-order system and explores time-domain performance metrics through simulation.

## Features
- Open-loop and closed-loop system modeling
- MATLAB-based step response analysis
- Controller design and effect on performance
- Stepinfo analysis and comparison
- Professional plots ready for publication

## Requirements
- MATLAB (R2021a or later recommended)
- Control System Toolbox

## Files
- cruise_control_model.m: Main MATLAB code
- plots/: Folder with all generated response plots
- report.pdf: Full documentation with analysis and diagrams
